# Player Commands Guide

🌐 **English** | [Português](README.pt.md) | [Español](README.es.md)

The list of every command players can use on the server, with what each one does and examples, lives on the site, so it always matches the plugins the server runs:

- **On the site:** <https://l4d2.com.br/commands>, grouped by what you want to do, with a search box.
- **In the game:** type `!comandos` or `!commands` to open the same list in the game panel.

## How to type a command

| Form | Example | Note |
|---|---|---|
| Chat with `!` | `!ready` | Everyone sees the command in chat |
| Chat with `/` | `/ready` | **Silent**, only you see the reply |
| Console (`~`) | `sm_ready` | Replace `!` with `sm_` |

The admin commands are in the [Admin Commands Guide](../admins/README.md).

Need help? Talk to an admin on the server.
