# Guia de Comandos para Jogadores

🌐 [English](README.md) | **Português** | [Español](README.es.md)

A lista de todos os comandos que os jogadores podem usar no servidor, com o que cada um faz e exemplos, fica no site, então ela sempre bate com os plugins que o servidor usa:

- **No site:** <https://l4d2.com.br/commands>, separada pelo que você quer fazer, com uma busca.
- **No jogo:** digite `!comandos` ou `!commands` para abrir a mesma lista no painel do jogo.

## Como digitar um comando

| Forma | Exemplo | Observação |
|---|---|---|
| Chat com `!` | `!ready` | O comando aparece no chat para todos |
| Chat com `/` | `/ready` | Fica **silencioso**, só você vê a resposta |
| Console (`~`) | `sm_ready` | Troque o `!` por `sm_` |

Os comandos dos admins estão no [Guia de Comandos para Admins](../admins/README.pt.md).

Precisa de ajuda? Fale com um admin no servidor.
