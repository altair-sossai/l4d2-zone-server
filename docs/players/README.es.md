# Guía de Comandos para Jugadores

🌐 [English](README.md) | [Português](README.pt.md) | **Español**

La lista de todos los comandos que los jugadores pueden usar en el servidor, con lo que hace cada uno y ejemplos, está en el sitio, así que siempre coincide con los plugins que usa el servidor:

- **En el sitio:** <https://l4d2.com.br/commands>, separada por lo que quieres hacer, con un buscador.
- **En el juego:** escribe `!comandos` o `!commands` para abrir la misma lista en el panel del juego.

## Cómo escribir un comando

| Forma | Ejemplo | Nota |
|---|---|---|
| Chat con `!` | `!ready` | Todos ven el comando en el chat |
| Chat con `/` | `/ready` | Es **silencioso**, solo tú ves la respuesta |
| Consola (`~`) | `sm_ready` | Cambia el `!` por `sm_` |

Los comandos de los admins están en la [Guía de Comandos para Admins](../admins/README.es.md).

¿Necesitas ayuda? Habla con un admin en el servidor.
