# Changelog del servidor — 19 de noviembre de 2026

🌐 [English](2026-11-19.md) | [Português](2026-11-19.pt.md) | **Español**

l4d2.com.br ahora funciona con [l4d2-playstats-hub](https://github.com/altair-sossai/l4d2-playstats-hub), que reemplaza el sitio antiguo (l4d2-playstats-web) y la API antigua de PlayStats (l4d2-playstats-api). Los plugins de estadísticas también se movieron allí.

## Plugins de estadísticas movidos a l4d2-playstats-hub

- **Movidos:** `l4d2_playstats_sync`, `l4d2_gameinfo_sync`, `l4d2_ranking`, `l4d2_show_patent_icon` y `l4d2_weapon_skins`, con sus traducciones y `configs/weapon_skins.cfg`, se quitaron de este repositorio. Se mantienen en [l4d2-playstats-hub](https://github.com/altair-sossai/l4d2-playstats-hub/tree/main/plugins).
- **Deploy:** en cada deploy, el pipeline descarga `l4d2-playstats-hub-plugins.zip` de la [última release del hub](https://github.com/altair-sossai/l4d2-playstats-hub/releases/latest) y copia su carpeta `addons` sobre el servidor.
- **Espera a que el servidor esté vacío:** el pipeline sube los archivos a `/home/devops/<build>` e inicia [`bash/deploy-when-empty.sh`](../../bash/deploy-when-empty.sh) en segundo plano. Solo extrae los archivos después de que `https://l4d2.com.br/api/servers` muestre 0 jugadores dos veces, con un minuto de diferencia, así que un deploy nunca cambia archivos durante una partida. Un build más nuevo reemplaza al que todavía está esperando. El log queda en `/home/devops/deploy-<build>.log`.
- **Sigue aquí:** `l4d2_playstats`, el plugin de Competitive Rework que escribe los archivos de estadísticas, las líneas `sm plugins load` y las ConVars de cada modo (`ranking_show_motd_panel`, `patent_icon_*`, `gameinfo_*`, `weapon_skins_*`).
- Detalles: [Plugins personalizados → Plugins de estadísticas](../plugins/README.es.md#plugins-de-estadísticas-l4d2-playstats-hub).

## Ajustes

- **Eliminados:** `playstats_url` apuntando a la API antigua en Azure, `ranking_url` y `playstats_access_token`.
- **Nuevos en `cfg/server.cfg`:** `playstats_url "http://124.198.128.43:5000"`, la dirección que usan los plugins y el navegador del juego, y `playstats_public_url "https://l4d2.com.br"`, la dirección que los jugadores leen en el chat. `l4d2_web_url` sigue siendo `https://l4d2.com.br`, ahora servido por el hub.
- **Token:** el token del servidor no está en el repositorio. El pipeline escribe `cfg/playstats_token.cfg` a partir de una variable secreta, y `server.cfg` lo ejecuta.
- Archivo: [`cfg/server.cfg`](../../cfg/server.cfg).
