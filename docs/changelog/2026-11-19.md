# Server changelog — November 19, 2026

🌐 **English** | [Português](2026-11-19.pt.md) | [Español](2026-11-19.es.md)

l4d2.com.br now runs on [l4d2-playstats-hub](https://github.com/altair-sossai/l4d2-playstats-hub), which replaces the old site (l4d2-playstats-web) and the old PlayStats API (l4d2-playstats-api). The statistics plugins moved there too.

## Statistics plugins moved to l4d2-playstats-hub

- **Moved:** `l4d2_playstats_sync`, `l4d2_gameinfo_sync`, `l4d2_ranking`, `l4d2_show_patent_icon` and `l4d2_weapon_skins`, with their translations and `configs/weapon_skins.cfg`, were removed from this repository. They are maintained in [l4d2-playstats-hub](https://github.com/altair-sossai/l4d2-playstats-hub/tree/main/plugins).
- **Deploy:** on every deploy, the pipeline downloads `l4d2-playstats-hub-plugins.zip` from the [latest hub release](https://github.com/altair-sossai/l4d2-playstats-hub/releases/latest) and copies its `addons` folder over the server.
- **Waits for an empty server:** the pipeline uploads the files to `/home/devops/<build>` and starts [`bash/deploy-when-empty.sh`](../../bash/deploy-when-empty.sh) in the background. It only extracts the files after `https://l4d2.com.br/api/servers` shows 0 players twice, one minute apart, so a deploy never changes files during a match. A newer build replaces one still waiting. The log stays in `/home/devops/deploy-<build>.log`.
- **Stays here:** `l4d2_playstats`, the Competitive Rework plugin that writes the statistics files, the `sm plugins load` lines and the per-mode ConVars (`ranking_show_motd_panel`, `patent_icon_*`, `gameinfo_*`, `weapon_skins_*`).
- Details: [Custom plugins → Statistics plugins](../plugins/README.md#statistics-plugins-l4d2-playstats-hub).

## Settings

- **Removed:** `playstats_url` pointing to the old Azure API, `ranking_url` and `playstats_access_token`.
- **New in `cfg/server.cfg`:** `playstats_url "http://124.198.128.43:5000"`, the address the plugins and the in-game browser use, and `playstats_public_url "https://l4d2.com.br"`, the address players read in chat. `l4d2_web_url` stays `https://l4d2.com.br`, now served by the hub.
- **Token:** the token of the server is not in the repository. The pipeline writes `cfg/playstats_token.cfg` from a secret variable, and `server.cfg` runs it.
- File: [`cfg/server.cfg`](../../cfg/server.cfg).
