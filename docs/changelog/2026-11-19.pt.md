# Changelog do servidor — 19/11/2026

🌐 [English](2026-11-19.md) | **Português** | [Español](2026-11-19.es.md)

O l4d2.com.br agora roda no [l4d2-playstats-hub](https://github.com/altair-sossai/l4d2-playstats-hub), que substitui o site antigo (l4d2-playstats-web) e a API antiga do PlayStats (l4d2-playstats-api). Os plugins de estatísticas também foram para lá.

## Plugins de estatísticas movidos para o l4d2-playstats-hub

- **Movidos:** `l4d2_playstats_sync`, `l4d2_gameinfo_sync`, `l4d2_ranking`, `l4d2_show_patent_icon` e `l4d2_weapon_skins`, com as traduções deles e o `configs/weapon_skins.cfg`, foram removidos deste repositório. Eles são mantidos no [l4d2-playstats-hub](https://github.com/altair-sossai/l4d2-playstats-hub/tree/main/plugins).
- **Deploy:** a cada deploy, o pipeline baixa o `l4d2-playstats-hub-plugins.zip` da [última release do hub](https://github.com/altair-sossai/l4d2-playstats-hub/releases/latest) e copia a pasta `addons` dele por cima do servidor.
- **Espera o servidor esvaziar:** o pipeline envia os arquivos para `/home/devops/<build>` e inicia o [`bash/deploy-when-empty.sh`](../../bash/deploy-when-empty.sh) em segundo plano. Ele só extrai os arquivos depois que `https://l4d2.com.br/api/servers` mostra 0 jogadores duas vezes, com um minuto de intervalo, então um deploy nunca muda arquivos durante uma partida. Um build mais novo substitui o que ainda está esperando. O log fica em `/home/devops/deploy-<build>.log`.
- **Continua aqui:** o `l4d2_playstats`, plugin do Competitive Rework que grava os arquivos de estatísticas, as linhas `sm plugins load` e as ConVars de cada modo (`ranking_show_motd_panel`, `patent_icon_*`, `gameinfo_*`, `weapon_skins_*`).
- Detalhes: [Plugins customizados → Plugins de estatísticas](../plugins/README.pt.md#plugins-de-estatísticas-l4d2-playstats-hub).

## Configurações

- **Removidas:** o `playstats_url` apontando para a API antiga no Azure, o `ranking_url` e o `playstats_access_token`.
- **Novas no `cfg/server.cfg`:** `playstats_url "http://124.198.128.43:5000"`, o endereço que os plugins e o navegador do jogo usam, e `playstats_public_url "https://l4d2.com.br"`, o endereço que os jogadores leem no chat. O `l4d2_web_url` continua `https://l4d2.com.br`, agora atendido pelo hub.
- **Token:** o token do servidor não fica no repositório. O pipeline grava o `cfg/playstats_token.cfg` a partir de uma variável secreta, e o `server.cfg` o executa.
- Arquivo: [`cfg/server.cfg`](../../cfg/server.cfg).
