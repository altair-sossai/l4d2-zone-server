# Server changelog — November 25, 2026

## Surrender without crashing the server

- **`!surrender`** in the second half of a map no longer crashes the server when everyone is slain. At the end of the second half the game writes the campaign score. The plugin reapplied the final score from inside that write, and the server went down and came back on the first map of Dark Carnival. Because of that, the surrendered map had no second half and did not show up on the site.
- The final score is now reapplied one frame after each score update of the game, never inside it.
- The infected are still prepared when the surrender passes, when round two goes live and right before everyone is slain, so the map is still recorded on the site.
- Two maps lost in those crashes were completed: `c5m2_park`, with the win of the team of good, inc, Finn ™ and Lpz *, and the 22:04 `c2m2_fairgrounds`, with the win of the team of ugLymofc;, inc, Feeh and ana over the team of waled.
- [`l4d2_early_victory`](../plugins/README.md#l4d2_early_victory) is now version 1.7.2.
