## Surrender without crashing the server

- **`!surrender`** no longer crashes the server when everyone is slain at the end of the surrender. Before, the plugin handled the infected inside the end of the round itself, and the server went down and came back on the first map of Dark Carnival. Because of that, the surrendered map had no second half and did not show up on the site.
- The infected are still prepared when the surrender passes, when round two goes live and right before everyone is slain, so the map is still recorded on the site.
- The `c5m2_park` map of today's match, lost in that crash, was completed with the win of the team of good, inc, Finn ™ and Lpz *.
- [`l4d2_early_victory`](../plugins/README.md#l4d2_early_victory) is now version 1.7.1.
