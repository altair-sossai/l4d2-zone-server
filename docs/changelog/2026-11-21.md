# Server changelog — November 21, 2026

🌐 **English** | [Português](2026-11-21.pt.md) | [Español](2026-11-21.es.md)

## Secrets written by the pipeline

- **`cfg/server_secrets.cfg`** is no longer uploaded by hand. The deploy pipeline writes it on every deploy from the secret variables `RCON_PASSWORD`, `PLAYSTATS_TOKEN` and `ANTI_CHEAT_ACCESS_TOKEN`, with permission `600`.
- **`cfg/playstats_token.cfg`** is gone: its two lines (`playstats_token` and `l4d2_web_secret`) are now in `server_secrets.cfg`, and the deploy deletes the old file from the server.
- **Anti-cheat settings that are not secret** (`anti_cheat_endpoint`, `anti_cheat_server_id` and `anti_cheat_download_url`) moved to [`cfg/server.cfg`](../../cfg/server.cfg).
- **Removed**: `playstats_access_token`, the token of the old PlayStats API, which nothing reads anymore.
- **Rotated**: `rcon_password` and `anti_cheat_access_token`.

## Mix from the community ranking

- **`!rmix`** (or `!rrmix`) starts a mix with the teams split by the community ranking of the site, instead of captains picking. It needs the same votes as `!mix`, and starting it raises the votes needed for the next mix the same way.
- The site tries every split of the players, keeps the most balanced ones and picks one at random, so the same players do not always get the same teams. The chat shows one line with the survivors and one with the infected.
- If anyone on the teams is not in the community ranking yet, the chat names them and the mix does not start.
- [`l4d2_mix`](../plugins/README.md#l4d2_mix-adapted) is now version 5.1.0 and needs REST in Pawn, already installed for the PlayStats plugins.

## Forced names from the site

- **[`l4d2_forced_names`](../plugins/README.md#l4d2_forced_names) 1.1.0** also reads the list of forced names kept on the site (**Administration > Forced names**) when the configs run and at the start of each round. The names from the site win over `configs/forced_names.cfg`, and the site shows the forced name on every page.
- The new ConVar `l4d2_forced_names_hub` turns it on; this server sets it to `1` in `shared_cvars.cfg` of zonemod and neomod.
- The 60 players of `configs/forced_names.cfg` were moved to the site. The file now has only one example line.
