# Server changelog — November 27, 2026

🌐 **English** | [Português](2026-11-27.pt.md) | [Español](2026-11-27.es.md)

## `!fix`: players fix health, give pills and pick up downed survivors by vote

- New **`!fix`** command, for when someone is harmed during the game and there is no admin on the server. It opens a menu with four options:
  - **Health of a survivor:** make all of the health permanent, or pick the permanent or temporary health among 100, 90, 80, 70, 60 and 50. The list shows each one's current health (*"Feeh - 37 + 20 temp"*).
  - **Give pills to a survivor:** only those with no pills and no adrenaline are listed.
  - **Revive a downed survivor:** down or hanging from a ledge.
  - **Restore the Tank's health:** only shown while a Tank is alive.
- The **other team** decides: the infected vote on requests for the survivors, and the survivors vote on the Tank health request. The vote uses the game keys (F1 yes, F2 no), lasts 15 s and passes with more Yes than No.
- By vote you can only ask for what does not lower anyone's health, so the voting team cannot harm the other team.
- It only works with the round live (outside the ready-up and the pause). Each player waits 60 s between requests, and each team gets at most 3 approved requests per round.
- For admins, `!fix` applies **right away**, with no vote, at any time.
- The chat tells everyone about each request and its result.
- New [`l4d2_fix`](../plugins/README.md#l4d2_fix) plugin, at version 1.0.0, loaded in ZoneMod and NeoMod.

## `!hp` removed

- The admin command **`!hp`**, which added health to every survivor at once, is gone from the server. To fix a survivor's health, use **`!fix`**, which shows everyone's health and lets you pick who to fix, or `!sethpplayer`.
- The `l4d2_admin_hp` plugin is no longer loaded in ZoneMod and NeoMod and was deleted from the repository.
