# Changelog do servidor — 21/11/2026

🌐 [English](2026-11-21.md) | **Português** | [Español](2026-11-21.es.md)

## Segredos gravados pelo pipeline

- **`cfg/server_secrets.cfg`** não é mais enviado à mão. O pipeline de deploy grava o arquivo a cada deploy a partir das variáveis secretas `RCON_PASSWORD`, `PLAYSTATS_TOKEN` e `ANTI_CHEAT_ACCESS_TOKEN`, com permissão `600`.
- **`cfg/playstats_token.cfg`** deixou de existir: as duas linhas dele (`playstats_token` e `l4d2_web_secret`) agora ficam no `server_secrets.cfg`, e o deploy apaga o arquivo antigo do servidor.
- **Configurações do anti-cheat que não são segredo** (`anti_cheat_endpoint`, `anti_cheat_server_id` e `anti_cheat_download_url`) foram para o [`cfg/server.cfg`](../../cfg/server.cfg).
- **Removido**: `playstats_access_token`, o token da API antiga do PlayStats, que nada mais lê.
- **Rotacionados**: `rcon_password` e `anti_cheat_access_token`.
